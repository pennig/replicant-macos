# Memory Index

- [Active replicant, not first](active-replicant-not-first.md) — multi-replicant invariant: never use roster.first / Replicant.fetchAll.first as a proxy for the active/current replicant; resolve via activeReplicantCode (count==1 fallback), reload distance sort on activeReplicantCode change, and fan event ingestion out over the whole roster when the event has no replicant_code (per-code scan debounce).

- [Same-step dispatch needs a tracked op](same-step-dispatch-needs-tracked-op.md) — a step dispatching with `nextStep` == its OWN step is safe ONLY for tracked kinds (`.travel`/`.mine`/`.print`/scan); for a `.simple` verb no Operation row exists so the `openOperation` guard is always nil, the command re-issues every tick forever, and `DirectiveExecutor` re-stamps `stepStartedAt` on each accepted dispatch so the step deadline can never fire. Split dispatch from polling (the `launching`/`awaiting` shape).
- [Confirm steps need fresh evidence](confirm-steps-need-fresh-evidence.md) — a polling step judging a LOCAL device row must first prove `updatedAt >= stepStartedAt`; nothing in a mission loop refreshes device rows, so a pre-dispatch row satisfies a loose check, the deadline never accumulates, and the run re-commands itself into a false stall — and the staleness guard must sit AFTER the deadline check or a failing read loops forever at ~12 `.high` reads/min. **Half three (2026-08-01)**: a DISPATCH step needs the same proof, keyed off the ARRIVAL not `stepStartedAt` — one arrival event closes the travel op and writes `device.location` in two separate transactions, so a tick landing between them re-commands travel at an already-parked vessel; filter the watermark op on `.completed` exactly, gate the dispatch path only, and test the gate's PLACEMENT (hoisting it above the location check broke exactly 1 of 335 tests). The `Reconciler.swift:256` same-second drop is a second, still-unfixed door to the same stall; `SurveyRun.swift:415`/`:475` still carry the pre-fix shape.
