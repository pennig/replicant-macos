# Fetch Run Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A user-launched `fetchRun` directive that flies the nearest free `fetch`-tagged surge plate to a device, attaches it, delivers it to a destination the user named, detaches it, and parks the plate at the theatre nearest the drop-off.

**Architecture:** A new `MissionStepMachine` assembled almost entirely from step values that already exist (`TravelTo`, `StowOrAttach`, `ReturnHome`, `ConfirmRow`). The one novel piece is `staging`, a priority ladder rather than a sequence, which is how a one-action-per-evaluation engine expresses "compact the payload while the plate flies to collect it". Two device leases are needed from launch: the plate through the existing `Directive.deviceCode` seed, and the payload through a new `Directive.payloadCode` column.

**Tech Stack:** Swift 6, SwiftPM package at `app/Modules`, Swift Testing (`@Test`/`#expect`), SQLiteData/StructuredQueries for persistence, The Composable Architecture for the launcher UI.

**Spec:** `docs/superpowers/specs/2026-08-23-fetch-run-design.md`

## Global Constraints

- **Mission machines are pure.** No I/O, no `Date()`, no randomness. Every clock read is `world.now`. One `MissionAction` per evaluation.
- **Migrations are append-only.** A new schema change appends to `GameDatabase.manifest`. Never edit, rename, or reorder a shipped one — GRDB keys applied migrations by identifier, so an edit silently never runs.
- **`DirectiveExecutor.commit` names its columns explicitly.** A new `Directive` column that is not added to that `update { }` block is written nowhere, with no error. This is the failure recorded in `app/.claude/memory/salvage-bot-roster-branch.md`.
- **Comment budget is hard:** file header ≤ 10 lines, `///` doc ≤ 4 lines, inline `//` ≤ 2 lines. No dated history, no rejected alternatives, no "we considered X". See `app/CLAUDE.md`.
- **No hard-coded colors, spacing, or font sizes** in any UI file. Use `DesignSystem.swift` tokens. Location and system designations render in a monospace token (`.rcMono`, `.rcMonoSmall`, or a prominence-matched variant).
- **Loud test defaults:** a client's `testValue` uses `unimplemented(...)`, never a quiet stub.
- **Pin test constants absolutely.** A fixture written relative to the constant it tests leaves that constant's value undefended (`app/.claude/memory/relative-fixtures-hide-constant-drift.md`). Prove each pin by mutating the constant and watching the test go red.
- **Never parse `swift test` console text.** The canonical invocation, used by every step in this plan:

```bash
cd app/Modules && swift test \
  --test-product <PRODUCT> \
  --disable-xctest \
  --event-stream-version 0 \
  --event-stream-output-path .build/events.jsonl \
  --filter '<SuiteTypeName>'

# failures (empty output = none)
jq -r 'select(.kind=="event" and .payload.kind=="issueRecorded")
       | "\(.payload.testID)"' .build/events.jsonl

# how many tests actually ran — gate on this, not on the absence of failures
jq -r 'select(.kind=="event" and .payload.kind=="testEnded") | .payload.testID' \
  .build/events.jsonl | wc -l
```

`<PRODUCT>` is one of `DirectiveEngineTests`, `GameModelsTests`, `GameDatabaseTests`, `DirectivesFeatureTests`. `--filter` matches the suite's **Swift type name**, never its `@Suite("display name")`.

- **New worktree setup, before any LSP query:** `cd app/Modules && swift build --build-tests`, then `./scripts/link-index-store.sh`. Without the second, every reference query silently returns zero.
- **Git:** commit to this worktree's branch. No PRs, no pushes to `origin`.

```swift
//
//  FetchRun.swift
//  Replicould — DirectiveEngine
//
//  One device moved from where it stands to a location the user named, on a
//  surge plate. Pure — every effect is the returned `MissionAction`, and time
//  comes from `world.now`.
//

import Foundation
import GameModels
import GameServices
import OSLog
import UniverseModels

private let logger = Logger(subsystem: "name.pennig.replicould", category: "DirectiveEngine")

public struct FetchRun: MissionStepMachine {
    public let kind: DirectiveKind = .fetchRun
    public var firstStep: String { Step.preflight.rawValue }

    public init() {}

    /// This mission's step vocabulary, as `Directive.step` holds it.
    public enum Step: String, CaseIterable, Sendable {
        /// Prove the plate and the payload before anything is commanded.
        case preflight
        /// Compact the payload and fly the plate to it, concurrently.
        case staging
        case attaching
        case confirmingAttach
        case delivering
        case detaching
        case confirmingDetach
        /// Park the plate at the theatre nearest where it dropped the payload.
        case homing
    }

    /// The hull this run flies. Not `surge_carrier` — a different, larger type.
    public static let plateDeviceType = "surge_plate"

    /// A bare tag, not a `FleetTag`: `FleetTag` parses `auto:<goal>` forms and
    /// would not match what the operator types.
    public static let fetchTag = "fetch"

    /// How stale a row may be and still be believed at preflight.
    public static let stagingFreshness: TimeInterval = 5 * 60

    /// How long an unconfirmed attach or detach is tolerated.
    public static let containmentDeadline: TimeInterval = 5 * 60

    public func nextAction(directive: Directive, world: WorldSnapshot) -> MissionAction {
        guard let step = Step(rawValue: directive.step) else {
            logger.notice("\(kind.rawValue, privacy: .public) \(directive.id, privacy: .public): unknown step \(directive.step, privacy: .public) — waiting")
            return .wait
        }
        switch step {
        case .preflight: return .wait
        case .staging: return .wait
        case .attaching: return .wait
        case .confirmingAttach: return .wait
        case .delivering: return .wait
        case .detaching: return .wait
        case .confirmingDetach: return .wait
        case .homing: return .wait
        }
    }

    /// A fetch run has no roam and must never finish itself through the
    /// queue-extension path.
    public func plan(_ context: RoamContext) -> RoamPlan { .idle }

    // MARK: - Reading the row

    /// Where the payload is collected. Pinned at launch, because the payload's
    /// own `location` goes nil the moment it is attached.
    public static func pickup(of directive: Directive) -> String? {
        directive.targets.count == 2 ? directive.targets[0] : nil
    }

    public static func destination(of directive: Directive) -> String? {
        directive.targets.count == 2 ? directive.targets[1] : nil
    }

    // MARK: - Plate selection

    /// The plate this run should fly to `pickup`: tagged, unleased, with a free
    /// attach slot, nearest first and device code as the tie-break.
    public static func plate(
        for pickup: String,
        in devices: some Sequence<Device>,
        reserved: Set<String>,
        positions: [String: Position]
    ) -> Device? {
        let origin = positions[SiteAssay.system(of: pickup)]
        return devices
            .filter { isEligible($0, reserved: reserved) }
            .min { lhs, rhs in
                let left = distance(from: origin, to: lhs, positions)
                let right = distance(from: origin, to: rhs, positions)
                return left == right ? lhs.deviceCode < rhs.deviceCode : left < right
            }
    }

    /// The predicate `plate(for:in:reserved:positions:)` ranks, exposed so
    /// preflight can re-validate the plate it was launched with.
    public static func isEligible(_ device: Device, reserved: Set<String>) -> Bool {
        device.deviceType == plateDeviceType
            && device.tags.contains(fetchTag)
            && !reserved.contains(device.deviceCode)
            && device.attachCapacity > device.attachedDeviceCodes.count
            && device.location != nil
    }

    /// A plate whose system the census has not placed sorts last rather than
    /// being excluded — it is still a usable hull.
    private static func distance(
        from origin: Position?, to device: Device, _ positions: [String: Position]
    ) -> Double {
        guard let origin, let location = device.location,
              let position = positions[SiteAssay.system(of: location)]
        else { return .infinity }
        return origin.distance(to: position)
    }
}
```

```swift
// MARK: - Steps

/// Prove the plate and the payload before anything is commanded. The plate is
/// never re-picked here: `deviceCode` is the lease.
private func preflight(_ directive: Directive, _ world: WorldSnapshot) -> MissionAction {
    guard let payloadCode = directive.payloadCode,
          let destination = Self.destination(of: directive)
    else { return .stall(.unreachableDevice) }
    let codes = [directive.deviceCode, payloadCode]
    guard let plate = world.device(directive.deviceCode),
          let payload = world.device(payloadCode)
    else { return .refreshDevices(deviceCodes: codes, thenStall: .unreachableDevice) }

    let stale = [plate, payload].contains {
        world.now.timeIntervalSince($0.updatedAt) > Self.stagingFreshness
    }
    if stale { return .refreshDevices(deviceCodes: codes, thenStall: nil) }

    if payload.location == destination { return .done }

    let ownership = Ownership.resolve(
        directives: world.peers, devices: world.devices, theatres: world.theatres
    )
    // The run's own claim is expected; anyone else's is the stall.
    if let rival = ownership.holders(of: payloadCode).first(where: { $0.directiveID != directive.id }) {
        return .stall(.fetchPayloadLeased, detail: rival.directiveID)
    }
    guard Self.isEligible(plate, reserved: []) else { return .stall(.noFetchPlateAvailable) }
    return .advanceStep(nextStep: Step.staging.rawValue)
}
```

`isEligible` is called with an empty `reserved` set on purpose: this plate is *supposed* to be leased, by this run.

```swift
/// Compaction and the plate's inbound flight, overlapped. The engine takes one
/// action per evaluation, so this is a priority ladder, not a sequence.
private func stage(_ directive: Directive, _ world: WorldSnapshot) -> MissionAction {
    guard let payloadCode = directive.payloadCode,
          let plate = world.device(directive.deviceCode),
          let payload = world.device(payloadCode),
          let pickup = Self.pickup(of: directive)
    else { return .stall(.unreachableDevice) }

    let ctx = StepContext(directive: directive, world: world, step: directive.step)
    let payloadBusy = ctx.openOperation(for: payloadCode) != nil
    let plateBusy = ctx.openOperation(for: plate.deviceCode) != nil

    if Self.needsCompacting(payload, world), !payloadBusy {
        return .dispatch(
            kind: .compact, deviceCode: payloadCode,
            params: CommandParams(), nextStep: Step.staging.rawValue
        )
    }

    let leg = TravelTo(
        deviceCode: plate.deviceCode, destination: pickup,
        arrivalTest: .exactLocation, confirmStep: Step.staging.rawValue
    )
    if !leg.hasArrived(plate), !plateBusy, case let .action(action) = leg.next(ctx) {
        return action
    }

    // Both halves, not just the plate: a payload mid-travel of its own would
    // otherwise reach an attach the server refuses.
    let settled = leg.hasArrived(plate) && !plateBusy
        && !Self.needsCompacting(payload, world) && !payloadBusy
    return settled ? .advanceStep(nextStep: Step.attaching.rawValue) : .wait
}

/// status can carry a suffix, and every other check in `Device` goes through it.

    world.modularDeviceTypes.contains(payload.deviceType) && payload.statusBase != "compacted"
```

```swift
private func attach(_ directive: Directive, _ world: WorldSnapshot) -> MissionAction {
    guard let payloadCode = directive.payloadCode else { return .stall(.unreachableDevice) }
    let ctx = StepContext(directive: directive, world: world, step: directive.step)
    let job = StowOrAttach(
        carrierCode: directive.deviceCode, deviceCodes: [payloadCode], verb: .attach,
        confirmField: .attachedTo, confirmStep: Step.confirmingAttach.rawValue,
```

The state's derived properties, written as static functions so they are testable without building a whole `State`:

```swift
/// Devices a plate could actually collect: standing somewhere, and not already
/// held by a running directive.
static func eligiblePayloads(in devices: [Device], reserved: Set<String>) -> [Device] {
    devices
        .filter { $0.location != nil }
        .filter { !reserved.contains($0.deviceCode) }
        .filter { $0.deviceType != FetchRun.plateDeviceType }
        .sorted { $0.deviceCode < $1.deviceCode }
}

/// A destination the payload already occupies is not a fetch.
static func canLaunch(payload: Device?, destination: String?, plate: Device?) -> Bool {
    guard let payload, let destination, plate != nil else { return false }
    return payload.location != destination
}
```

## Verification the plan does not cover

Two things cannot be checked from a background job and are the operator's:

1. **A live fetch end to end.** Running the app needs a Keychain login. `xcodebuild` proves it compiles; it proves nothing about a real plate flying.
2. **Whether `compact` is actually accepted on a payload standing loose at a location.** Every test here asserts what the machine *dispatches*, not what the server does with it. If the API refuses `compact` on some device class, the run stalls `commandRejected` at `staging` and the fix is a preflight filter on the payload picker.
